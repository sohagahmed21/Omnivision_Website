OMNIVISION WEBSITE STARTER
==========================

FILES
- index.html: Home page, navbar, footer
- style.css: Shared responsive styling
- script.js: Mobile menu, dropdowns, image slider, current year
- Particals/: Individual content pages

IMPORTANT BEFORE RUNNING
1. Copy your four background images to:
   assets/images/pic1.jpg
   assets/images/pic2.jpg
   assets/images/pic3.jpg
   assets/images/pic4.jpg

   If your images use different names, update the four background-image paths in index.html.

2. Replace every occurrence of 8801XXXXXXXXX in the HTML files with your WhatsApp number in international format, digits only.
   Example format for Bangladesh: 8801XXXXXXXXX
   Do not include +, spaces, or hyphens in the wa.me URL.

3. Open index.html in your browser, or use VS Code Live Server.

4. The company copy, services, client information, news, blog, and team content are starter text. Replace with verified Omnivision information before publishing.

5. The project uses only HTML, CSS, and vanilla JavaScript. Google Fonts are loaded from an external service; the site still uses fallback fonts if unavailable.

NOTE
The folder name "Particals" is preserved as requested. The Contact Us page filename is "contact us.html"; its links may contain a URL-encoded space (%20).
